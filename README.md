# 📊 HR Analysis Dashboard

A Power BI--based HR Analytics project designed to help organizations
understand employee metrics such as attrition, performance,
department-wise distribution, salary insights, and more. This project
converts raw HR data into meaningful visualizations to support
data-driven decision-making.

## 🚀 Features

-   📉 **Attrition Analysis** -- Track employee exits by age, gender,
    department, salary, education, etc.
-   👥 **Employee Demographics** -- Distribution based on job role,
    department, education level.
-   💰 **Salary Insights** -- Salary trends across departments and
    experience levels.
-   📈 **Performance Metrics** -- Insights into ratings and
    performance-related attributes.
-   🧭 **Interactive Visuals** -- Fully interactive Power BI charts and
    filters.
-   📂 **Clean Data Modeling** -- Organized data model optimized for
    reporting.

1.  Download/clone the repository
2.  Open **HR Analysis.pbix** in Power BI Desktop
3.  Interact with the dashboards using slicers and filters
4.  Modify visuals or add new insights as needed
